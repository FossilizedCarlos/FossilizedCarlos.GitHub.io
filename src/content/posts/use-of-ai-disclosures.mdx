I have been thinking a lot about how the things I am building might eventually find other uses for other people. Knowing this, and knowing the way some people feel about LLMs... I have decided to start adding badges to the repos of things I built with the assistance of agents.

I created the following badges to add to my repos, using [Shields.io](https://shields.io/badges/static-badge) and [Simple Icons](https://simpleicons.org), so people can see that I used LLM tools in some form to create that code.

I am also thinking on how to separate any posts that are generated by agents, that can be helpful to others, but would have their own author style tags describing the models and harness used. Everytime I solve a problem or do something, I request a guide or postmortem to save for future use, as this will save me from needing to fix the same issues twice. In the grand scheme, my hope is to prevent the use of token to consistenly solve the same problems.
